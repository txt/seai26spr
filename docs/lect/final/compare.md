| **Methods (data + eval + rig)** | 19 high-dim MOOT tasks. T0 UCB_GPM, T1 single-step WS+TPE, T1b SynthCore M=20 repro, T2=H1 iterative LLM (20 rds x 4), T3=H2 constraint-aware, T4=H3 LLM dim-red. | **Discussion** | Iterative loop closes most of high-dim gap. T2 within 3pp of pub SC at fewer LLM calls. H1+ensemble combo justified only if disjoint task subsets. | RQ1: GP advantage not free; RBF good middle at n<200. RQ2: degradation non-uniform -- GP worst on structured, kNN consistent on multimodal high-d. RQ3: kNN conditionally yes for high-d multimodal w/ large BO budgets. | 5 framing Qs: knee != compromise (T4 won); explanation gain proportional to 1/tech-level; role > cog-style for what, GenderMag drives how; Abi/Pat confusion (40-48%) validates GenderMag; practice: never raw to non-tech, include stab metadata, show full frontier. | Bottleneck = retriever, not prompt. BM25 needs lexical overlap; rewriting optimises tokens for clean queries (helps), can't recover overlap removed by adversary (hurts). Prompt evolution proves prompt-quality is not the constraint. GraphCodeBERT side-steps lexical mismatch entirely. Rewriting hurts GraphCodeBERT because it strips identifiers dense retrieval already exploits. |
| **Threats to Validity** | Baseline instability [17]->[18]: UCB_GPM 100->68, R+TPE 47->16. Pilot B1=20 not yet matched-budget.
