Title Rescuing LLM-Guided Optimization on High-Dimensional Software Configuration Tasks Surrogate Model Selection Under Budget Constraints: Accuracy, Data, and Computational Cost Trade-offs Bridging the Interpretation Gap: LLM-Generated Explanations for Multi-Objective Optimisation Trade-offs in SE Improving Robustness of Neural Code Search via Prompt-Evolved Query Reformulation
Motivation LLM warm-starts top-rank at low/med dim, fail at |x|>11 (53% vs UCB_GPM 100%). Two parallel rescues exist (SynthCore, BtP), neither feeds outcomes back. 19 high-dim tasks = 39% of benchmark; failure not niche. Expensive evals (hrs–weeks/pt). Trade-offs handled by 10n rules-of-thumb, not quantitative. kNN absent from surrogate guides despite cheap+frugal. MOOT optimisers output Pareto fronts/trees as numbers, no requirements meaning. Stakeholders reason differently. No prior work combines LLM-explain + MO-opt + multi-stakeholder + SE. Code search collapses under identifier-renaming perturbations. Lexical retrievers depend on identifier overlap. Can query rewriting fix this without retraining the retriever?
Background Storm 480× perf loss; x264 1536 hrs full label; 90% TD false-positives mislabeled. SynthCore M=20 ensemble; BtP stat/RAG; OPRO/LLAMBO iterative on single-obj only. NFL: no single best surrogate. GP accurate-slow, RBF fast-init-sensitive, NN data-hungry. 10n rule (McKay/Loeppky). Existing studies: compute = secondary metric. Amershi HAI guidelines; Bucinca: cognitive-forcing helps only if comprehensible; Shin: explainability ≠ causability. GenderMag: 5 cog facets, 200+ studies. Schuller: LLM personas ≈ human-written. Early code search = lexical/structural (Sourcerer, Portfolio, CodeHow, DeepAPI). Neural shift = joint embedding (DeepCS) → CodeBERT/GraphCodeBERT/CodeT5/UniXcoder. Robustness lags: semantics-preserving xforms break models.
Related Work 6-D positioning table. WS=fail; SynthCore=parallel ensemble; BtP=domain knowledge; LLAMBO/GPTuner/OPRO/MOEA-D-LLM iterative but single-obj/non-SE. Centre of Venn empty; H1 fills it. 5 lit groups: data/sampling, search/cost, methodology/benchmarking, NFL theory, domain adaptation. Gap: kNN not viable surrogate; cost-acc trade-off not made exact. 4 threads: persona sim (Schuller, Camburu); XAI-DT (Serafim, Ziems, Sivaprasad); multi-stakeholder XAI (Kim, Dhar, Mavrepis, Mill); MO+stakeholder (Shao 2014, pre-LLM). 6 buckets: classical retrieval, neural code search, pretrained code models, query reformulation (CoaCor, SSQR), robustness/adversarial (Yefet, MHM), prompt opt (EvoPrompt, PromptBreeder). 28-paper Venn shows prompt-opt × adv-code-search intersection = empty.
Methods
(data + eval + rig)		 19 high-dim MOOT tasks. T0 UCB_GPM, T1 single-step WS+TPE, T1b SynthCore M=20 repro, T2=H1 iterative LLM (20 rds × 4), T3=H2 constraint-aware, T4=H3 LLM dim-red. Matched 20 calls/84 labels. Scott-Knott + paired bootstrap, 20 seeds, Chebyshev. 4 funcs (Rosenbrock/Rastrigin/Ackley/Styblinski–Tang) × d∈{2,5,10} × n∈{20,50,100,200,500}. GP/RBF/NN/kNN (k via 5-fold CV). Exp1: 720 RMSE pts on 300-pt LHS test. Exp2: BO 10+40, 5 seeds, EI for GP/kNN, exploit for RBF/NN. MOOT project-health (A2C, 223 cfg, 10 feats, 3 obj). EZR opt → N=400 calibrated → 5 Pareto trees. 9 personas = 3 roles × 3 GenderMag (Abi/Pat/Tim) via Gemini 2.5 Flash. 2-rd counterbalanced (raw vs explained), 90 evals. Judges: Claude Sonnet 4.5 + Llama 3.1 70B. CodeXGLUE NL-code-search-Adv (clean+adv, 9.6k val / 19.2k test). Retrievers: BM25 (k₁=1.5, b=0.75) and GraphCodeBERT (microsoft/graphcodebert-base, no fine-tune). 3 conditions: raw, fixed-prompt rewrite (CamelCase split, underscore→space, punct/whitespace), prompt-evolved (PromptBreeder hill-climb, 25 iter, ε=0.003, patience 5, 300-query dev set). MRR + robustness drop.
Results Pilot B1=20: T2 high-dim rank-0 = 68% vs T1 48% (+20pp, sig); T0=66%; pub SC ref 71%. Low 100→93 (within margin); med 64→79. T1b/T3/T4 pending. GP best 2D/5D smooth; kNN flat except Ackley 10D (excels). All converge at n≤50 high-d. At 10D kNN no longer Pareto-dominated. BO: kNN-EI on Ackley-10D 7.50±0.29 vs GP 6.73±0.39; NN-exploit weakest. RQ1: accept 16→51% (+35pp); clarity 1.96→4.16; suff 1.56→3.67. RQ2: H1/H3/H4/H5 supported, H2/H6 partial. 67% chose T4 (not knee T5). RQ3: full-persona judge acc 45.6/32.2 vs 11.1% chance; PjM-Tim 0%; learning-style α=0.22. BM25 val: clean MRR 0.1654 → adv 0.0518 (−68.7%). Fixed-prompt rewrite: clean ↑ to 0.1878, adv ↓ to 0.0474 (worse). Prompt evolution: every mutation underperforms seed → no improvement. GraphCodeBERT raw: 0.5262/0.5285 (zero degradation). Same rewrite on GraphCodeBERT cuts perf 23–28%.
Discussion Iterative loop closes most of high-dim gap. T2 within 3pp of pub SC at fewer LLM calls. H1+ensemble combo justified only if disjoint task subsets. RQ1: GP advantage not free; RBF good middle at n<200. RQ2: degradation non-uniform — GP worst on structured, kNN consistent on multimodal high-d. RQ3: kNN conditionally yes for high-d multimodal w/ large BO budgets. 5 framing Qs: knee≠compromise (T4 won); explanation gain ∝ 1/tech-level; role > cog-style for what, GenderMag drives how; Abi/Pat confusion (40–48%) validates GenderMag; practice: never raw to non-tech, include stab metadata, show full frontier. Bottleneck = retriever, not prompt. BM25 needs lexical overlap; rewriting optimises tokens for clean queries (helps), can’t recover overlap removed by adversary (hurts). Prompt evolution proves prompt-quality is not the constraint. GraphCodeBERT side-steps lexical mismatch entirely. Rewriting hurts GraphCodeBERT because it strips identifiers dense retrieval already exploits.
Threats to Validity Baseline instability [17]→[18]: UCB_GPM 100→68, R+TPE 47→16. Pilot B1=20 not yet matched-budget. SC’s L+M(N+1) formula deviation documented. Internal: 1 LHS draw/cell, no replication (BO 5 seeds = small). External: smooth math funcs, no noise/disc; d∈[2,10] excludes d>20. Construct: RMSE on LHS test ≠ local acc near optima. Internal: counterbalanced groups unbalanced by role (G1=PjM, G2=SWE); single generator LLM. External: other MOOT tasks; only 3 roles. Construct: LLM personas ≠ humans. Conclusion: learning_style unobservable in static format; LLM stochasticity. No labelled section. Implicit: single benchmark (CodeXGLUE-Adv only), single language (Python), no fine-tuned GraphCodeBERT (off-the-shelf checkpoint), heuristic rewriter deterministic so doesn’t exhaust rewrite-space, prompt-evolution dev set fixed at 300 queries.
Conclusion Iterative LLM (H1) most promising at pilot; full matched-call protocol pending. Replication package preserves Chebyshev. Section empty (placeholder only). Framework + tailored explanations. Accept 16→51%, clarity doubled, compromise ≠ knee. 3 failure modes + judge validation. First to combine LLM-explain + MO-opt + GenderMag + acceptance eval in SE. Prompt-side fixes don’t rescue adversarial code search. BM25 collapses; rewrites help clean, hurt adv; evolution never beats seed. GraphCodeBERT loses nothing to perturbation, beats BM25 >10× on adv. Retriever > prompt.
