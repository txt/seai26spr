# Glossary + Review Questions: OO Tutorial & Naive Bayes

## Glossary

_Gotta catch 'em all._

### Data Architecture

**`Sym(dict)`**
  Symbolic column. Subclass of dict — frequencies for free.
  No `__init__` needed.

**`Num(list)`**
  Numeric column. Subclass of sorted list — median, norm,
  spread all fall out of sort order.

**`Data`**
  Container of rows + a `Cols` object. Delegates everything
  (mid, distx, disty, pick, like) to its columns.

**`Cols`**
  Factory that reads header names and builds `Num`/`Sym`
  instances into `x`, `y`, `all`, `klass`, `w` dicts.

**Polymorphic delegation**
  Data asks columns to do things; Num and Sym each respond
  differently. One interface, two implementations.

**Column naming conventions**
  Uppercase first letter → Num. Lowercase → Sym.
  `+` = maximize, `-` = minimize, `!` = class label,
  trailing `X` = ignore.

### Reservoir Sampling

**Reservoir sampler**
  Fixed-size random sample of a stream. Once full, each new
  value has probability `mx/seen` of replacing a random
  existing value.
  ```python
  if len(i) < i.mx: insort(i, v)
  elif r() < i.mx/i.seen:
      i.pop(int(r()*len(i))); insort(i, v)
  ```

**`insort`**
  Binary search for location (log n), then insert. On a
  256-item list Python's block-move is negligible.

### Summary Statistics

**`mid`**
  Central tendency. Num → median (`i[len(i)//2]`).
  Sym → mode (`max(i, key=i.get)`).

**`spread`**
  Diversity. Num → (90th − 10th percentile) / 2.56.
  Sym → entropy: `-Σ p·log₂(p)`.

**2.56**
  Distance between 10th and 90th percentiles of a standard
  normal. Dividing the percentile range by 2.56 estimates
  σ without assuming Gaussian shape.

**`norm`**
  Rescale a Num to [0,1] using 5th–95th percentile as
  lo/hi. Resists outlier distortion.

**`_mid` cache**
  `None or expr` — lazy evaluation. `add`/`sub` reset
  it to `None`; recomputed only when asked.

### Distance

**`distx`**
  Distance in x-space (inputs). Delegates per-column:
  Sym → 0 if same, 1 if different.
  Num → `|norm(a) − norm(b)|`, unknowns assume max.
  Combined via Minkowski.

**`disty`**
  Distance to heaven in y-space (goals).
  `norm(v) − goal` where goal is 1 (maximize) or
  0 (minimize). Combined via Minkowski.

**Minkowski distance**
  `(Σ dᵢᵖ / n)^(1/p)`. p=2 → Euclidean. Averaged over
  columns so result stays in [0,1].

**Heaven**
  Ideal point: all goals at their best simultaneously.

### Mutation (pick)

**`Sym.pick`**
  Sample from seen values, weighted by frequency.

**`Num.pick`**
  `v + choice(i) − choice(i)` — symmetric random step
  from the actual data distribution. No Gaussian needed.

**Wrap-around**
  `(result − lo) % (hi − lo)`. Overshoots jump to the
  other side instead of piling up at boundaries.

### Python Idioms

**Walrus operator `:=`**
  Assign mid-expression:
  `if (p := i[k]/n) > 0`.

**Docstring as config**
  Regex finds `key=value` in `__doc__`, casts to
  int/float/str, builds `the` namespace.

**`next(items := iter(items))`**
  Pop header row; remaining `items` are data rows.

**Annotations as coercers**
  `f.__annotations__` values used as cast functions:
  `int`, `float`, custom `file_name` checker.

**`bool("false")` trap**
  Returns `True` — any non-empty string is truthy.

### Naive Bayes

**Prior**
  `P(class) = (n_class + m) / (n_all + m·n_h)`.
  Base rate before seeing evidence.

**Likelihood**
  `P(row | class)` — product of per-column likelihoods.
  Sym: frequency ratio. Num: Gaussian pdf using median
  and spread.

**Posterior**
  Prior × likelihood. We never compute it; we just rank.

**Naive independence assumption**
  Each feature is independent given the class.
  Almost never true. Works anyway (see Optimality).

**Log-likelihood**
  `log(prior) + Σ log(likelihood_i)`.
  Addition instead of multiplication avoids underflow.
  ```python
  return log(prior) + sum(log(v) for v in ls if v>0)
  ```

**Laplace smoothing (m, k)**
  Low-frequency hacks. `k` smooths attribute counts,
  `m` smooths class priors. Defaults k=1, m=2.
  Vanish for large sample sizes.

**Zero problem**
  One unseen value zeros the entire product.
  Smoothing + log guard (`v > 0`) prevent this.

**`Sym.like`**
  `(count + k·prior) / (n + k)`. Floored at `1/BIG`.

**`Num.like`**
  Gaussian pdf: `(1/√(2πσ²)) · exp(-(v-μ)²/2σ²)`
  using median for μ and spread for σ.

**Ranker, not estimator**
  NB's probability estimates are often wrong, but its
  rankings are correct. Denominator P(row) cancels —
  only need to compare numerators.

### Classifier Mechanics

**`nbayes` (online learner)**
  Each row: predict first, train after. Never cheats.
  `ks` dict maps class → its own `Data`.

**Warmup**
  Wait for N rows before predicting. Sparse tables
  are untrustworthy.

**`every`**
  A `Data` holding all rows regardless of class.
  Provides `n_all` for the prior formula.

### Confusion Matrix & Evaluation

**True Positive (D), True Negative (A)**
  Correct classifications.

**False Positive (C, FP), False Negative (B, FN)**
  Errors. FP = flagged but wasn't. FN = missed.

**Recall (pd)**
  `D / (B+D)`. Of actual positives, how many caught?

**False alarm (pf)**
  `C / (A+C)`. Of actual negatives, how many flagged?

**Precision (prec)**
  `D / (D+C)`. Of flagged items, how many real?

**Accuracy (acc)**
  `(A+D) / (A+B+C+D)`. Overall correct rate.

**One-vs-rest**
  For N classes, make N binary tables (X vs not-X).
  Each class gets its own pd/pf/prec/acc.

**Incremental confusion**
  New class initialized with `tn = total` — all prior
  rows retroactively count as true negatives.

**Precision instability**
  `prec = 1 / (1 + (neg/pos) × pf/recall)`.
  As neg/pos grows, the space of high-precision
  detectors shrinks. Small Δpf → huge Δprec.

**G-measure**
  `2 × recall × (1−pf) / (recall + 1−pf)`.
  Harmonic mean using recall and false alarm — avoids
  precision instability.

**AUC**
  Area under ROC curve (pf vs recall). 1.0 perfect,
  0.5 random. Threshold-free.

**D2H (distance to heaven)**
  `√((1−recall)² + pf²) / √2`. Single number, [0,1].

**IFA (initial false alarms)**
  False alarms before first true detection. Trust
  measure for developers.

**MCC (Matthews correlation coefficient)**
  `(TP·TN − FP·FN) / √((TP+FP)(TP+FN)(TN+FP)(TN+FN))`.
  Uses all four cells. Fair on imbalanced data.

### Optimality & Fixes

**Domingos & Pazzani (1997)**
  NB is optimal under zero-one loss over half the
  volume of all (p,r,s) combinations. Only needs the
  ranking sign, not the magnitude.

**Small sample advantage**
  NB has O(features) parameters → low variance. Beats
  complex models when n < ~1000.

**Complement Naive Bayes (CNB)**
  Estimate weights using all rows NOT in the class.
  Fixes skewed training data.

**Weight normalization**
  Divide each weight by L1 norm of class vector.
  Fixes correlated-feature inflation.

### Active Learning

**Active learning**
  Choose which unlabeled example to label next, given
  a fixed budget.

**SMAC**
  Random forest surrogate. Rebuild all trees per step.
  O(T × B² log B) total. Days to run.

**BEST / REST split**
  Top √n labeled rows = BEST. Rest = REST.
  Two-class Bayes surrogate.

**Acquisition function**
  `log P(r|REST) − log P(r|BEST)`. Minimize → pick
  the row most like BEST, least like REST.
  O(features) per step. Minutes to run.

**Eager vs lazy acquire**
  Eager: full scan of pool, pick global best.
  Lazy: random walk, stop at first promising row.

**Demote worst BEST → REST**
  When BEST exceeds √n members, pop the worst and
  push to REST via `sub`/`add`. O(1) per column.

## Review Questions

### Q1 — Subclassing Built-ins

**(a)** Why is `Sym` a subclass of `dict` and `Num` a
subclass of `list`? Name one method each inherits for
free. *(2 min)*

**(b)** Suppose you wanted to add a third column type,
`Ord`, for ordinal data (e.g. "low", "med", "high"
with a known ordering). Should it subclass `dict` or
`list`? What would `distx`, `mid`, and `pick` look
like? Justify your choices. *(4 min)*

### Q2 — Reservoir Sampling

**(a)** What is the maximum size of a `Num`'s internal
list, and what happens when a new value arrives after
the list is full? *(2 min)*

**(b)** A colleague argues reservoir sampling biases
toward recent data. Is that true? If 10 million rows
have passed through a reservoir of size 256, what is
the probability that any specific earlier row is still
in the sample? What guarantee does the algorithm
provide about representativeness? *(4 min)*

### Q3 — Spread Without Gaussians

**(a)** Write the formula for `Num.spread` and explain
where the constant 2.56 comes from. *(2 min)*

**(b)** You have SQL query response times: most cluster
around 50ms, but there's a second hump at 200ms
(bimodal). Compare what `Num.spread` reports vs a
standard-deviation calculation assuming Gaussian.
Which is more useful for characterizing this data, and
why? *(4 min)*

### Q4 — Polymorphic Delegation

**(a)** When `Data.distx` is called, which classes
actually compute the per-column distances? What does
Sym return and what does Num return? *(2 min)*

**(b)** Trace the delegation chain for
`Data.like(row, n_all, n_h)`. Which columns are
iterated (x or y)? Why is the class column excluded?
What would go wrong if `cols.y` columns were included
in the likelihood calculation? *(4 min)*

### Q5 — Log-Likelihood and Smoothing

**(a)** Why do we add logs instead of multiplying raw
probabilities in Naive Bayes? *(2 min)*

**(b)** Consider a dataset with 10,000 horses and 10
snakes. A new row has attribute `has_rider`. No snake
in training has a rider. Walk through the calculation
with k=0 (no smoothing) and k=1 (Laplace). Show the
exact values. Why does k=0 destroy the snake class's
entire likelihood? *(4 min)*

### Q6 — Ranking vs Probability

**(a)** State the key insight from Domingos & Pazzani
about when Naive Bayes is optimal under zero-one
loss. *(2 min)*

**(b)** NB estimates P(horse|row) = 0.85 and
P(snake|row) = 0.15, but the true values are 0.60 and
0.40. Does NB classify correctly? Now suppose the true
values are 0.45 and 0.55. Draw the "zone of confusion"
and explain why, as the number of features grows, this
zone shrinks. *(4 min)*

### Q7 — Confusion Matrix Arithmetic

**(a)** Given TP=15, FN=5, FP=10, TN=70, compute
recall, false alarm, precision, and accuracy. *(2 min)*

**(b)** You have 90 elephants and 10 dogs. A lazy

its accuracy, recall for dogs, and precision for dogs.
Now explain why accuracy is misleading here, and which
measure (recall, pf, or precision) best exposes the
problem. *(4 min)*

### Q8 — Precision Instability

**(a)** Write the formula relating precision to
neg/pos ratio, pf, and recall. *(2 min)*

**(b)** Dataset A has neg/pos = 2. Dataset B has

Compute precision for each. Now drop pf to 0.05 and
recompute. In which dataset does precision change more
dramatically, and why does this make cross-dataset
comparison of precision unreliable? *(4 min)*
