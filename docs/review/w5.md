## Glossary

### Search Basics

**Candidate solution**
  A single row — a list of values, one per column. The thing
  being optimized.
  ```python
  s = choice(d.rows)[:]   # pick a random row, copy it
  ```

**Decision space / Objective space**
  Xs = all possible rows (inputs). Ys = their quality scores
  (outputs). We never see the full space; we get a budget.

**Budget `b`**
  Hard cap on evaluations. When `h >= b`, stop.
  ```python
  while True:
      if h >= b: return
  ```

**Energy**
  Scalar quality of a row — distance from "heaven" (ideal Ys).
  Lower = better. All search = minimize energy.
  ```python
  def disty(d, r):
      return minkowski(
          (norm(y, r[y.at]) - y.goal) for y in d.cols.y)
  ```

**`y.goal`**
  1 = maximize this column, 0 = minimize. Set from column name.

**Minkowski distance**
  Generalises Euclidean (p=2) and Manhattan (p=1):
  `(Σ dᵢᵖ / n)^(1/p)`. Used to aggregate Y distances.

---

### Surrogates & Oracles

**Oracle**
  Anything that labels a row's Y values: a human expert
  (~10–20 labels/hour), a simulator, a build system, an LLM.

**Surrogate model**
  A cheap approximation of the oracle used to guide search.
  Doesn't need to be accurate — only needs to rank correctly
  ("A is better than B").

**Cheap oracle trick (nearest-neighbor surrogate)**
  Borrow Y values from the closest already-labeled row instead
  of evaluating from scratch.
  ```python
  def score(r):
      near = nearest(d, r, d.rows)
      for y in d.cols.y:
          r[y.at] = near[y.at]
      return disty(d, r)
  ```

**Surrogate alternatives**
  Nearest neighbor, decision trees, neural nets, Naive Bayes,
  human expert, LLM. All produce rankings; accuracy ≠ efficacy.

**"Bad learners make good optimizers"** *(Nair 2017)*
  Surrogate error rate is uncorrelated with optimization
  quality. Surrogates only need ordinal correctness, not
  precise prediction.

**Naive Bayes as surrogate**
  Two-class Bayes (best vs. rest) runs ~5× faster than SMAC
  (100-tree ensemble) and matches it on 127 SE problems.
  Tiny memory; supports incremental add/delete via Welford.

### The 1+1 Loop

**1+1 optimizer**
  One current solution + one mutant. Keep the better.
  The shared engine for SA and local search.
  ```python
  for sn in mutator(s):
      h += 1; en = score(sn)
      if accept(e, en, h, b):
          s, e = sn, en
      if en < best_e:
          best, best_e = sn[:], en
          yield h, best_e, best
  ```

**Strategy pattern (functional)**
  `accept` and `mutate` are passed in as lambdas. The loop,
  budget, and restart logic are shared. Only the strategy
  differs between algorithms.

**M+N optimizer (contrast)**
  Genetic algorithms: maintain a population of M things,
  breed N offspring. Much more expensive than 1+1.

**Generator as search engine**
  `oneplus1` uses `yield`, not `return`. The caller controls
  when to stop; the engine just supplies better solutions.
  ```python
  for h, e, row in sa(d1):   # pull one improvement at a time
      says([h, e] + row, w=8)
  ```

---

### Hill Climbing (Local Search)

**Hill climbing / local search**
  Accept only if strictly better. Fast; gets stuck in local
  optima.
  ```python
  def accept(e, en, *_):
      return en < e       # *_ discards h and b
  ```

**Variable neighborhood search**
  With prob `p`, take `n` steps along one axis (deep probe);
  otherwise take one step (wide probe). Escapes shallow optima.
  ```python
  def mutate(s):
      x = choice(list(d.cols.x))
      for _ in range(n if rand() < p else 1):
          sn = s[:]; sn[x.at] = nearby(x, sn[x.at]); yield sn
  ```

**`nearby(x, v)`**
  Mutates value `v` by an amount scaled to the column's
  standard deviation. Symbols: pick any other value.

---

### Simulated Annealing

**Simulated annealing (SA)**
  Accept worse solutions early (exploration); tighten as budget
  runs out (exploitation). Boltzmann acceptance criterion:
  `P = exp((e - en) / (1 - h/b))`

**Cooling schedule**
  `1 - h/b` starts near 1 (hot, permissive) → 0 (cold,
  strict). SA becomes hill climbing at end of budget.
  ```python
  def accept(e, en, h, b):
      return en < e or rand() < exp((e - en) / (1 - h/b))
  ```

**Multi-feature mutation (SA)**
  Mutates `m` fraction of all X features per step (default
  m=0.5). Larger jumps suit high-temperature exploration.
  ```python
  for x in choices(list(d.cols.x), k=max(1,int(m*len(d.cols.x)))):
      sn[x.at] = nearby(x, sn[x.at])
  ```

---

### Restarts

**Random restart**
  If no improvement in `restart` evaluations, abandon the
  current basin and jump to a new random start. O(1) cost.
  ```python
  if restart and h - last_improvement > restart:
      s, e, last_improvement = choice(d.rows)[:], 1E32, 0
      break   # exits for-loop; while restarts from scratch
  ```

**Why restarts dominate**
  In the 2×2 experiment: SA+restart ≈ LS+restart. The
  acceptance policy matters less than escaping local optima.
  "Restarts are insanely powerful."

**Chronological backtracking (contrast)**
  Classic alternative: undo the last decision and try another.
  Slow when the real error is early in the decision sequence.

### Statistics for Stochastic Algorithms

**Reproducible randomness**
  Set and publish seeds. Every `random.seed(s)` call makes
  runs deterministic and reproducible.
  ```python
  random.seed(float(sys.argv[1]))
  ```

**Why run 20+ times**
  Stochastic algorithms produce a *distribution* of outcomes,
  not a single result. Read the tails, not just the median.

**Cliff's delta (effect size)**
  For each number in list A, count how many in list B are
  bigger vs. smaller. Normalize. Small delta = distributions
  overlap = uninteresting difference. Non-parametric.
  ```python
  def cliffs(a, b, small=0.147):
      n = sum(1  for x in a for y in b if x > y) \
        - sum(1  for x in a for y in b if x < y)
      return abs(n) / (len(a) * len(b)) < small
      # True  → difference is too small to matter
      # False → lists are interestingly different
  ```

**KS test (distinguishability)**
  Plot both CDFs; measure maximum vertical distance between
  them. Zero = identical; 1 = no overlap. Non-parametric.
  "Are you distinguishable?" not "Are you significant?"
  ```python
  def ks(a, b, small=0.05):
      all  = sorted(set(a + b))
      n, m = len(a), len(b)
      fa = fb = 0; big = 0
      for x in all:
          fa += sum(1 for v in a if v == x) / n
          fb += sum(1 for v in b if v == x) / m
          big = max(big, abs(fa - fb))
      return big < small
      # True  → CDFs are close → not distinguishable
      # False → CDFs are far apart → distributions differ
  ```

**Non-parametric tests**
  Cliff's delta and KS make no Gaussian assumption. Essential
  for SE data which is rarely bell-shaped.

### Multi-Objective Concepts

**Hypervolume / spread / generational distance**
  Literature buzzwords for multi-objective quality. Hypervolume
  = area dominated by the found front. Treat as background
  reading; not used in this code.

**Active learning / decision boundary**
  When ranking is uncertain (x ≈ y in surrogate), sample near
  that confusion zone to resolve the boundary cheaply.

---

### SE Principles in the Code

**n − √n rule**
  Only ~√n of n variables tend to matter for any given task.
  Justifies lightweight models and column subsampling.

**Privacy via small corners** *(Filip Peters)*
  Task-relevant data occupies a tiny subspace. Share only
  that corner; the rest is 100% private. Corner changes per
  task, so the data owner retains control.

**Composite pattern**
  Messages sent to a container are echoed to its parts.
  `mid(data)` → `mid(col)` for each column → `mid(Num/Sym)`.

**Welford with w = −1**
  Passing weight −1 decrements instead of increments, enabling
  row *deletion* from a live model. Supports Naive Bayes
  surrogate updates without full rebuild.

**`try/except` for type coercion**
  ```python
  casts = [int, float, str]
  def cast(x):
      for c in casts:
          try: return c(x)
          except: pass
      return x
  ```
  Called for every cell of every CSV row — defined once at
  load time to avoid repeated construction cost.

**`__name__ == "__main__"`**
  File can be imported (no side effects) or run directly
  (calls `main()`). Standard Python module boundary.

**Annotations as cast instructions**
  ```python
  def eg_s(n:int): the.seed = n
  # main() reads f.__annotations__ → {'n': int}
  # pops CLI arg, casts with int(), passes it in
  ```
  Not a type check — a dispatch instruction.
