# Week4: CSC491 Review Notes


## Part 1: Glossary

### Python Idioms (from `ez.py`)

**Expressions & Assignment**

- **ternary expression** — one-line `a if cond else b`; returns a value
- **multiple assignment** — `a, b = 1, 2`; assigns several vars at once
- **walrus operator `:=`** — assigns *and* returns a value in one expression (Python 3.8+)
- **chained comparison** — `u == v == "?"` tests both conditions in one shot
- **short-circuit `or`** — `x or default`; returns default when x is falsy
- **f-string** — `f"{val:.{n}f}"` — format string; width/precision can be variables

**Collections & Iteration**

- **list comprehension** — `[f(x) for x in xs if cond]`; builds a list inline
- **dict comprehension** — `{k: v for k, v in pairs}`; builds a dict inline
- **generator expression** — like list comp but lazy; no `[]`, values on demand
- **`yield`** — suspends a function and returns one value; resumes on next call
- **`yield from`** — delegates to a sub-generator, forwarding all its values
- **`iter()` / `next()`** — `iter()` wraps any iterable; `next()` pulls one item
- **`enumerate`** — yields `(index, value)` pairs from any iterable

**Functions**

- **first-class function** — a function stored in a variable or passed as an argument
- **lambda** — anonymous single-expression function; e.g. `lambda x: x*2`
- **`*args` splat** — expands a list into positional arguments
- **`**kwargs` double-splat** — expands a dict into keyword arguments
- **factory function** — capitalized function that returns a configured `OBJ`
- **`__doc__`** — a function's docstring, accessible at runtime
- **`__name__`** — a function's name as a string, accessible at runtime
- **`__annotations__`** — dict of argument type hints; used to count CLI args
- **`__name__ == "__main__"`** — guard that runs CLI only when file is run directly
- **reflection** — code querying its own functions/metadata at runtime

**OOP / Typing**

- **`OBJ` class** — `dict` subclass; wires `__getattr__`/`__setattr__` for dot access
- **duck typing** — checking `.it` field instead of using `isinstance()`
- **`is` identity check** — pointer comparison; `SYM is col.it` faster than `isinstance`
- **conditional method selection** — `(a if cond else b)(arg)`; picks then calls

**Error Handling & IO**

- **`try`/`except` as control flow** — `cast` tries `int`, `float`, lambda in turn
- **`ValueError`** — specific error raised by `int()`/`float()` on bad input; catch this, not `Exception`
- **`with` statement** — ensures file closes even on crash
- **`match`/`case`** — structural pattern matching (Python 3.10+); like typed switch
- **`.get(key, default)`** — safe dict lookup; returns default instead of `KeyError`
- **`traceback` module** — captures crash info as string so test suite can continue
- **`run()`** — wraps a test call; prints stack on failure and moves to next test

**Algorithms in `ez.py`**

- **Welford's algorithm** — single-pass incremental mean (`mu`) and variance (`m2`)
- **Bessel's correction** — `n-1` denominator in `sd`; unbiased sample estimate
- **Shannon entropy** — `-Σ p·log₂(p)`; measures uncertainty in symbolic data
- **CDF normalization** — maps a value to 0–1 via z-score + sigmoid; robust to outliers
- **z-score** — `(v - mu) / sd`; clamped to [-3, 3] in `ez.py`
- **Aha distance** — heterogeneous distance; symbols: 0/1; numerics: |norm(u)−norm(v)|
- **missing-value heuristic** — unknown value assumed worst case (max distance from known)
- **Minkowski distance** — generalises Manhattan (p=1), Euclidean (p=2); divided by n features
- **distance to heaven (`disty`)** — Minkowski distance from a row to the ideal goal point
- **goal column** — y-column with `+` (maximise), `-` (minimise), or `!` (classify) suffix
- **Laplace smoothing** — adds `k·prior` to avoid zero-probability symbols in Naive Bayes
- **`the.k` / `the.m`** — smoothing constants; prevent zero probs wiping log-sum in `likes`
- **spread tree** — decision tree that minimises weighted `sd` or `ent` in leaves
- **expected spread** — weighted sum of leaf spreads; smaller = better split
- **`add` / `sub`** — update or undo column stats one value at a time; `sub` passes `w=-1`
- **separation of concerns** — `csv` handles IO; `DATA` handles columns; neither knows the other
- **composite pattern** — outer loops over parts (`adds`, `likes`, `distx`); inner handles one (`add`, `like`, `aha`)
- **`cast`** — tries `int`, `float`, bool-dict in order; returns first success
- **`CASTS` pipeline** — ordered list of converters; `try`/`except` selects the right one
- **`coerce pipeline`** — raw CSV string → `cast` → typed Python value
- **`pick`** — weighted random selection from a dict by walking cumulative counts
- **`gauss`** — approximates normal distribution via Central Limit Theorem (sum 3 uniforms)

### Dimensionality & Data Reduction (Keohoe 1995)

- **n − √n rule** — in most datasets, up to n − √n columns can be ignored
- **row reduction** — similar rows collapse to centroid exemplars; ~√n rows sufficient
- **tiny corner** — the √cols × √rows core that captures most of a dataset's information
- **span** — minimum number of vectors (columns) needed to describe a data space
- **redundant column** — column expressible as a combination of others; droppable
- **noise column** — column with no signal; uncorrelated with any target; droppable

---

### Symbolic Modeling vs LLMs

- **LLM** — large language model; trillion parameters; expensive and compute-heavy
- **symbolic model** — small, interpretable rule/tree model; runs without GPU
- **edge computing** — running inference on local/small devices, not cloud servers
- **VC subsidy** — venture capital currently making LLM inference artificially cheap
- **agent** — autonomous AI component; ideally lightweight and replaceable

---

### Simulated Annealing

- **temperature** — decreasing control parameter that governs escape probability
- **cooling schedule** — plan for lowering temperature over time
- **greedy search** — always move to best local neighbour; used at end of SA run
- **random walk** — move regardless of score; behaviour at *start* of SA run
- **local optimum** — solution better than all neighbours but not globally best
- **escape probability** — `exp(-(curr-best)/temp)`; higher when temp is high

---

### Reproducibility

- **random seed** — integer initialising the RNG; same seed = same sequence
- **CLI seed** — seed settable from command line so runs are exactly reproducible
- **per-test reset** — reseed before each test so ordering cannot corrupt results

---

### Euclidean Distance Geometry

- **normalised space** — all values mapped to [0, 1] enabling fair distance comparison
- **max distance √n** — diagonal of unit hypercube in n dimensions
